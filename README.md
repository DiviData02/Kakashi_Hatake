
Kakashi Hatake — Python Turtle Art

A Python Turtle Graphics project that draws a stylized portrait of Kakashi Hatake from Naruto. 
The project uses coordinate-based shapes, outlines, and colour fills to build the character piece by piece.

Features :--
  Draws Kakashi's hair, face, ears, headband, eyes, and mask using Turtle Graphics.
  Uses colour-filled shapes and outlines to make the portrait more recognizable.
  Uses Python's built-in turtle module, which relies on Tk/Tcl GUI support.
  Keeps the drawing code in a single Python file for easy running and editing.

Requirements :--
  Python 3 installed on Windows (or another OS with a working Tk/Tcl installation).
  No separate pip install turtle is normally required because turtle is included with standard Python installations.
